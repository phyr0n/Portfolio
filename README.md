# Portfolio

This repository contains the source code for my personal developer portfolio, hosted with Cloudflare at https://adamtait.net/. It is a React-based website written using TypeScript. Vite was also used to assist with deploying the website.

## Build Instructions

To build the project locally, follow these instructions:

```bash
# Clone the repository.
git clone https://github.com/phyr0n/Portfolio.git

# Install dependencies.
yarn

# Start the local development server.
yarn dev
```
